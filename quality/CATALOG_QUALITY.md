# 작품 카탈로그 품질 정책

## 목적

검색 API가 반환한 레코드와 사람이 검수한 추천 카탈로그를 분리한다. 검색 후보는 탐색에는 사용할 수 있지만, 아래 출시 기준을 통과하기 전에는 Connection Mode 추천에 노출하지 않는다.

## 상태

- `candidate`: 외부 무료 API에서 수집했으며 검수 전인 후보
- `curated`: 편집 기준과 메타데이터 기준을 모두 통과한 자체 검수 작품
- `verified`: 운영 검수자가 근거 자료로 확인한 작품
- `quarantined`: 권별 상품, 세트, 외전, 학습서, 웹소설 또는 메타데이터 결손이 큰 레코드

## 출시 기준

추천 대상은 `curated` 또는 `verified`이면서 품질 점수 90점 이상이어야 한다. 다음 항목을 모두 요구한다.

- 명확한 제목과 창작자
- 유효한 발표 연도
- HTTPS 대표 이미지
- 작품을 식별할 수 있는 설명
- 갈등·핵심 이미지·확장을 압축한 편집 한줄평
- 매체와 판본을 구분하는 canonical key

외부 API 결과는 서버가 임의로 검수 상태로 승격할 수 없다. 기존 검수 데이터는 외부 검색 결과로 덮어쓰지 않는다.

## 이미지와 한줄평

- 영화는 TMDB의 작품 ID와 포스터를 우선한다.
- 애니메이션은 AniList 공식 커버를 사용한다.
- 만화 시리즈는 권별 검색 결과 대신 시리즈 단위로 묶고 1권 표지를 사용한다.
- 한줄평은 작품명을 재언급하거나 추상 명사를 나열하지 않고, 작품의 구체적 갈등이나 이미지를 한 번의 비유로 전달한다.

## 운영 절차

1. `/api/metadata-quality`에서 후보와 격리 레코드를 확인한다.
2. 공식·출판사·권위 있는 카탈로그 근거를 확인한다.
3. 누락 필드를 보완하고 중복·각색·리메이크를 구분한다.
4. 품질 점수 90점 이상인지 확인한 뒤에만 `curated` 또는 `verified`로 승격한다.
5. 추천 평가와 브라우저 검증을 통과한 뒤 배포한다.
