# Stage 73 선택적 AI 보조

## 원칙

AI 보조는 추천 서비스의 필수 경로가 아니다. 기본 소개글과 Taste DNA는 검증된 메타데이터·어휘 엔진으로 항상 생성된다. 자체 호스팅했거나 무료 운영이 확인된 OpenAI 호환 로컬 모델만 선택적으로 후보를 제안할 수 있다.

유료 토큰 API 호스트는 코드에서 차단한다. 활성화에는 `LOCAL_AI_ENABLED=true`, `LOCAL_AI_ZERO_COST_ACK=true`, `LOCAL_AI_MODEL`, `LOCAL_AI_CHAT_ENDPOINT` 네 값이 모두 필요하다. 원격 주소는 HTTPS여야 하며 개발용 localhost만 HTTP를 허용한다.

## 개인정보

모델에는 제목, 원제, 창작자, 매체, 연도, 작품 설명과 공개 태그만 보낸다. 사용자의 이메일, ID, 별점, 한줄평, 저장 목록과 추천 반응은 보내지 않는다. 개인 감상문은 기존 엔진에서만 처리한다.

## 품질 게이트

- 소개글은 한국어 한 문장, 18~100자, `작품.`으로 끝나야 한다.
- 현학적 용어, 상투적 표현, 제목 재진술, 직접적인 결말 누설 표현을 거부한다.
- Taste DNA는 기존 25개 허용 어휘 가운데 3~8개만 수용한다.
- 호출 제한은 3.5초이며 오류·지연·형식 불일치 시 기존 엔진으로 즉시 복귀한다.
- 큐레이션으로 확정된 소개글은 AI가 덮어쓰지 않는다.

## 운영 확인

검수 화면의 `OPTIONAL AI ASSIST` 카드에서 활성 상태와 안전장치를 확인한다. 운영 환경은 기본적으로 비활성화되어 있으므로 별도 무료 모델을 연결하지 않아도 기능과 추천 품질이 동일하게 유지된다.
