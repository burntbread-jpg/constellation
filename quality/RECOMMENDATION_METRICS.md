# Stage 72 추천 학습 지표

## 출시 지표

- 추천 노출: 사용자 화면에 반환된 추천 카드 수
- 좋아요율: 좋아요 상태로 새로 전환한 횟수 ÷ 추천 노출
- 숨기기율: 숨기기 상태로 새로 전환한 횟수 ÷ 추천 노출
- 성좌 저장률: 추천에서 이동해 새로 저장한 작품 수 ÷ 추천 노출
- 매체 이동률: 출발 매체와 다른 매체의 추천 노출 ÷ 전체 추천 노출

동일한 좋아요·숨기기 상태를 반복 저장한 요청은 다시 집계하지 않는다. 이미 성좌에 있는 작품을 다시 저장하거나 백업으로 복원한 경우에도 추천 저장으로 집계하지 않는다.

## 개인정보 최소화

분석 테이블에는 날짜, Connection Mode, 출발 매체, 도착 매체, 행동 종류와 합계만 저장한다. 사용자 ID, 작품 ID, 이메일, IP, 자유 입력문, Taste DNA 태그는 저장하지 않는다. 집계 행은 730일 뒤 자동 삭제한다.

원본 추천 반응은 개인화 기능을 위해 사용자 소유 데이터로 별도 보관되며 기존 계정 삭제와 730일 보존 정책을 따른다.

## 접근 통제

- 테이블은 RLS를 활성화하고 `anon`, `authenticated`, `PUBLIC` 권한을 거부한다.
- 집계 함수는 `service_role`만 실행한다.
- 대시보드 API는 로그인한 지정 검수자에게만 일별·모드별 합계를 반환한다.
- 대시보드는 원본 이벤트나 개인별 데이터를 제공하지 않는다.
